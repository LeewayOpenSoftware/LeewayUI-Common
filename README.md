# LeewayUI Common

Leeway Open Software's shared application framework for desktop apps: ribbon (LeewayUI F1), frame template (status bar, zoom slider, ribbon|pill chrome), theme (light/dark/high-contrast/classic), DPI, and the Aureline icon set.

Owner: Leeway Open Software. Private repository.

## Status
This repository is the canonical home of LeewayUI Common. The code is currently developed inside LiberNT-LDW and has **not been migrated yet** (see `docs/STATUS.md`). Nothing has been moved or deleted from LiberNT.

## Consumers
- LiberNT (LeewayOpenSoftware/LiberNT-LDW): Photo Viewer (shimgvw), Paint (mspaint), WordPad (planned), `leewayui_ribbon_test`.
